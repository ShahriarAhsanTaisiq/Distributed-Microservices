# Distributed Microservices

A collection of projects and examples demonstrating distributed microservices architecture using Java and Spring Boot. This repository documents my learning journey through practical implementations of service discovery, API Gateway, centralized configuration, inter-service communication, messaging, resilience, containerization, and cloud-native development.

## 📌 Objectives

- Learn distributed system design principles
- Build scalable microservices using Spring Boot
- Explore Spring Cloud ecosystem
- Understand service-to-service communication
- Implement fault tolerance and resilience
- Containerize applications using Docker
- Deploy cloud-native applications
